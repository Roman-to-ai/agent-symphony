# 贯穿案例与实践记录

> 本文是教学场景与演练方案，不是本项目已完成的运行报告。

## 1. 目标与契约

场景：过期会话访问个人页时跳到登录页，登录后返回原页面；不允许通过恶意返回地址跳到外站。交付物是补丁、测试和验证报告。示例不包含真实生产操作授权。

验收至少覆盖有效会话、过期会话、取消登录、非法返回地址和前后端错误码一致性。范围限定认证模块及相应界面和测试。

## 2. 分工与依赖

| 任务 | 输入 | 输出 | 依赖 |
| --- | --- | --- | --- |
| A 定义契约 | 目标与现有行为 | 字段、状态码、允许的回跳规则 | 无 |
| B 后端实现 | A | 会话检查和错误响应 | A |
| C 前端实现 | A | 跳转、回跳和错误处理 | A |
| D 测试设计 | 目标与 A | 局部和集成场景 | A |
| E 集成验收 | B、C、D | 逐条证据与失败项 | B、C、D |

组织上设置一个协调者，B、C、D 在边界明确后并行，E 由独立审核者执行。若只有一处配置错误，则退回单 Worker，不为了练习结构而人为扩大实际任务。

## 3. 通信与状态

B 接收后确认范围；完成本地测试后提交补丁及证据；若环境不可用，报告 blocked 并明确需要谁解除。协调者维护权威状态，不能把 B 在线解释为 B 即将完成。

每项产物绑定契约版本、尝试 ID 和版本引用。E 按同一标准检查，并把通过、不通过、无法判定分开。

## 4. 恢复演练

| 注入点 | 预期结果 | 应采集证据 |
| --- | --- | --- |
| B 产出补丁后退出 | 新实例读取补丁与进度后继续 | 交接包、恢复日志 |
| 重复发送 B 的结果 | 只处理一次有效提交 | 消息 ID、状态版本 |
| C 被替换后旧实例回报 | 旧尝试无法覆盖新结果 | 拒绝记录、当前代次 |
| 协调者中断 | 接管者重建待办和验收项 | 持久任务记录 |
| 外部创建成功但响应丢失 | 查询或幂等重试，不重复创建 | 业务操作 ID 与外部记录 |

最后一项可以使用隔离的模拟服务；不要为了演练在真实外部系统制造副作用。

## 5. 资源与授权

限制模型并发和总预算，将共享测试环境作为独占资源。接近预算上限时停止新的探索分支，保留必要验收余量。若引入发布步骤，必须增加相应的明确授权和版本校验。

## 6. 评估与记录模板

比较单 Worker 和上述协作设计，使用相同目标、工具范围和验收条件；记录所有尝试，包括失败。

| 字段 | 本次填写 |
| --- | --- |
| 日期、环境、协议版本 | 待实测 |
| 任务与契约版本 | 待实测 |
| 模型、工具和资源限制 | 待实测 |
| 组织结构与选择理由 | 待实测 |
| 总耗时、成本与失败次数 | 待实测 |
| 通过、不通过、无法判定项 | 待实测 |
| 故障检测与恢复结果 | 待实测 |
| 与基线差异、解释和限制 | 待实测 |
| 下一次只改变的变量 | 待实测 |

练习完成后，只有填入可追溯证据的条目才能称为实测结论。
